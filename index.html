🔢 2. SCORE FORMULA (how we calculate)
Component Formula Range
Time Points 59 − time_taken (faster = more points) 0–58
Amuse Score min(40, raw score from AmuseLabs) 0–40
TOTAL SCORE Time Points + Amuse Score 0–98
EXAMPLE: 10s solve, AmuseLabs sends score=40 → (59-10)+min(40,40) = 49+40 = 89
AmuseLabs score = number of letters revealed (max ~40 points)
If timed out: score forced to 0, status=expired
⏱️ 3. TIMER: OUR TIMER vs AMUSELABS TIMER
Timer How it works
OUR TIMER Counts DOWN from 60s. Starts when PUZZLE_LOAD fires. time_taken = 60 − timeLeft at solve
AMUSE TIMER AmuseLabs sends timeTaken in its COMPLETE event. We PREFER this value if present
Priority if (data.timeTaken > 0) use AmuseLabs; else use our 60-timeLeft
Both timers start at the same moment (PUZZLE_LOAD). In practice they are the same, but AmuseLabs value is more precise.
🔗 4. HOW USER & GAME ARE LINKED
Table / API Field Note
save-user user_name, Bearer token (header) Token proves identity
save-game user_id + Bearer token (header) user_id IS the link between user & game
Token is NOT stored in the game record. It is ONLY in the Authorization header so the backend can verify the caller. The user_id field inside save-game is what joins the two tables in the DB.
🎮 5. AMUSELABS POSTMESSAGE EVENTS
Event When Data We Read
PUZZLE_LOAD (or type includes LOAD) Iframe ready id/puzzleId → State.gameId; starts our 60s timer
COMPLETE / progress=SOLVE etc. User solves timeTaken/duration used in score; triggers onComplete()
EXPIRE Puzzle time out Triggers onExpire()
⚠️ g_id FALLBACK RISK: If AmuseLabs does not send id in PUZZLE_LOAD, g_id defaults to 30. In production, monitor the console for "[GameBridge] g_id not received" and alert the AmuseLabs team immediately.
📎 6. DATE URL — HOW IT WORKS
Param Format Example
?date= YYYYMMDD or YYYY-MM-DD ?date=20260421
On load, we extract ?date= and compare it to today's IST date. If they match, the puzzle loads. If the QR code has an old date, the user sees the expired screen. This prevents old QR codes from being replayed. The QR code printed on the paper MUST contain today's date in the URL.
